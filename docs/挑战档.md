# 挑战档：实时字幕、DeepSeek 纪要、虚拟背景

本次按用户确认只完成挑战档前三项，交付在 `D:/Go_WorkSpace/comeet`。HTTPS 公网上线、Prometheus 与日志检索不属于本次范围，基础档和进阶档功能继续保留。

## 快速启动

需要 Go、Node.js/npm、Python 3.11–3.13。先复制 `.env.example` 为 `.env`，在后端配置自己的 DeepSeek 密钥：

支持系统自带的 Windows PowerShell 5.1 与 PowerShell 7。项目 `.ps1` 文件统一使用 UTF-8 BOM，`.editorconfig` 已声明该规则；保存脚本时请保留 BOM，避免 5.1 把中文误读成语法符号。`scripts/check.ps1` 会自动执行真实 5.1 引擎的脚本兼容性检查。

```dotenv
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_API_KEY=在本地填写自己的密钥
```

系统环境变量优先于 `.env`；密钥不使用 `VITE_` 前缀、不进入前端构建、接口响应或日志。已配置同名系统变量时，不会被 `.env` 覆盖。

```powershell
.\scripts\start-challenge.ps1
```

脚本在项目虚拟环境安装 Python 依赖，默认加载轻量 Whisper tiny，启动仅监听 `127.0.0.1:8091` 的 STT，再通过现有脚本启动 LiveKit、构建前端和启动 Go。访问 `http://127.0.0.1:8080`。首次模型下载需要网络、磁盘空间；tiny 约 75 MB，small 约数百 MB。已有本地 CTranslate2 模型时，可通过 `-Model '模型目录的绝对路径'` 指定。

默认 tiny 优先保证本机启动速度，需要更高识别质量时可选择 small（首次需要额外下载）：

```powershell
.\scripts\start-challenge.ps1 -Model small
```

退出时按 Ctrl+C，脚本清理本次启动的 STT 和 LiveKit 子进程；8091/7880 被其他服务占用时停止并提示，避免误停现有服务。STT 日志在 `data/stt.*.log`，音频和转写正文不会写入日志。

启动脚本使用 `npm ci` 确保依赖与锁文件一致。Windows 上应先关闭本项目正在运行的 Vite 开发服务器，否则其占用的原生 Node 模块可能导致安装报 EPERM；无需提权或修改系统权限。

已有 STT 或希望分步启动：

```powershell
# 终端 A：默认 tiny，可选 -Model small；模型加载后 /health 才返回 ready=true。
.\scripts\start-stt.ps1

# 终端 B：也可以把 STT_BASE_URL 写入 .env，然后启动进阶应用。
$env:STT_BASE_URL='http://127.0.0.1:8091/v1'
.\scripts\start-advanced.ps1
```

STT 支持兼容 `POST /audio/transcriptions` 的 multipart 服务：配置 `STT_BASE_URL`、可选的 `STT_API_KEY`、`STT_MODEL`。URL 应包含 `/v1` 前缀（若供应商要求），后端在末尾拼接 `/audio/transcriptions`。本地模型由 `start-stt.ps1 -Model` / `WHISPER_MODEL` 决定；`STT_MODEL` 是远端兼容协议字段，本地服务忽略该字段。若启用本地服务的 `STT_SERVICE_KEY`，同时把同一个值设为 Go 的 `STT_API_KEY`。

DeepSeek 官方模型名称已按 2026-11-11 文档核对：默认 `deepseek-flash`，可通过 `DEEPSEEK_MODEL` 调整；DeepSeek 仅负责纪要，不执行语音识别。未配置时页面明确提示，不返回伪造纪要或以模板结果冒充模型结果。

## 实时字幕

1. 各成员开启自己的麦克风，在“实时字幕”勾选“识别本人发言”。默认关闭，不替用户打开麦克风。
2. AudioWorklet 连续采集本人音轨，约每四秒生成一个完整 PCM16 WAV。优先使用 16 kHz，兼容服务会对其他采样率转换。
3. Go 从 JWT 和当前 WebSocket 会话确认成员身份，校验麦克风、字幕开关和主持人限制，再调用 STT。浏览器不能指定其他人的身份。
4. STT 返回后再次检查会话与静音/离会状态；迟到结果丢弃。有效转写写入 SQLite 并通过现有 WebSocket 广播。
5. 页面显示说话人、时间和最新三条字幕。重连按 ID 补齐，完整转写可在“字幕记录与 AI 纪要”及会后详情中分页查看和导出。

这是一种**短片段、准实时 STT**，延迟至少为片段长度加模型推理/网络时间，不宣称逐字流式识别。中英文分别选择，不支持同段自动双语识别。音频不写入业务数据库或录制目录，STT 直接在内存中处理；文本作为会议资料保留。若改成第三方 STT，音频将传往该服务，使用方需要告知参会者。

静音、主持人禁麦、关闭字幕、离会或会话替换都会中止浏览器识别链。每人最多一个在途请求，全局最多四个请求，本地 CPU 模型一次处理一个；处理速度不足时明确提示并跳过积压片段，不无限排队。小于 0.2 秒的尾片段和停止时尚未发出的不足四秒片段不会补传；低电平静音片段跳过，以减少空音频识别幻觉。STT 失败不会自动重试产生重复计费，继续下一段或由用户重新开启。

客户端每段有唯一编号，重复请求不会重复保存；服务端只接受 0.2–8 秒、最多 2 MiB 的规范 WAV。录制与字幕是独立开关，录制不自动开启字幕，字幕不自动保存音频。

## DeepSeek AI 会议纪要

主持人在会中点击“字幕记录与 AI 纪要”，或会后“详情与回放”中点击“生成纪要”。界面明确说明会将本场字幕和聊天文本发送给 DeepSeek；其他参会者可读取已保存结果，不能发起生成。

输出包括概述、已明确决定、行动项（任务/负责人/期限）、风险和待确认问题。模型请求使用 JSON 输出模式，服务端验证结构、长度和结束状态，页面按纯文本展示，不能执行返回的 HTML 或 Markdown 脚本。系统提示要求资料中的指令仅作为会议内容，不能覆盖系统角色；未知负责人或期限应写“未明确”。模型仍可能误判，纪要必须由人核对。

字幕和聊天在同一个数据库快照中读取，来源哈希随纪要保存。生成过程中有新内容时，读取纪要会提示资料已更新。每场同一时刻只允许一次生成；失败或取消不会覆盖旧版。模型超时为 120 秒。为避免静默丢失资料，单次最多 5000 条或 120 KB 来源文本；超限明确报错，可导出完整转写分段处理。

纪要保存在 `minutes` 表，转写保存在 `captions` 表，迁移幂等，不清空原有用户、会议、聊天和录制。支持 `.md` 纪要导出、全部转写 `.txt` 导出；会中只缓存最近 500 条字幕，历史分页读取完整数据。

## 虚拟背景

在入会准备页或会中“设备检测”选择“背景虚化”或“简约工作室”。实现使用真实的 MediaPipe Selfie Segmenter 模型：人像概率 → 柔化透明掩膜 → Canvas 保留人物 → 叠加模糊原背景或工作室背景。

模型文件随源码提交，固定版本及 SHA256 记录在 `web/public/models/README.md`，保留上游 Apache-2.0 许可。WASM 从锁定 npm 包复制到本机静态目录；`npm run dev/build` 自动准备，无需运行时 CDN。模型和所有摄像头帧均在本地浏览器处理，不上传到 STT/DeepSeek。

合成视频为 640×360、约 15fps，音轨原样保留，合成流同时用于本地预览、P2P/SFU 发布和会议录制。共享屏幕不受影响。摄像头关闭时同步禁用合成轨道。切换设备/模式/离会会停止旧分割器、定时器与合成轨道；原始设备由 `useMedia` 统一管理。

开启效果后，模型未就绪或加载失败期间不会退回发送原始摄像头，避免真实背景短暂暴露。用户主动选择“关闭”才恢复原视频。头发、手指、快速移动和光线不足时可能出现分割误差；该功能不构成可靠的隐私遮挡保障。实际硬件帧率与通话质量仍需设备验收。
